# **App Name**: StreamlineU

## Core Features:

- Login / Signup: Secure authentication with Firebase Authentication, supporting mobile number, email, password, and social login (Google, Microsoft, Facebook).
- Profile Management: Capture user data (course, semester, college name) and store it in Firestore.
- AI-Powered Academic Assistant: Provide subject-specific help, concept explanations, notes summarization, practice questions, and doubt solving, all powered by AI and retrievable using Firebase Cloud functions acting as a tool.
- Notes Repository & Summarization: Enable students to upload notes/PDFs, with AI summarization and storage in Firestore.
- Personalized Planner & Reminders: Add assignments, deadlines, and goals; generate AI-based study plans with reminders and notifications. Optional: Pomodoro timer, habit tracker.
- Career Guidance & Mentorship: Suggest internships, courses, certifications, resume/cover letter guidance, and career path options.
- Campus Life & Events: Display college-specific events, workshops, and clubs; AI answers college life questions and acts as a tool that provides guidance. Uses user's Firestore profile data for personalization.

## Style Guidelines:

- Primary color: Deep Blue (#1E3A8A), evoking a sense of trust and professionalism suitable for an educational app.
- Background color: Light Blue (#D1D5DB), a very light desaturation of the primary.
- Accent color: Purple (#7E22CE), used for interactive elements and highlights, providing contrast and visual interest.
- Body and headline font: 'Inter' (sans-serif) provides a clean and modern aesthetic, appropriate for on-screen reading.
- Use clear, modern icons to represent features. Icons should follow a consistent style for a cohesive look.
- Clean, mobile-friendly layout with a clear dashboard showcasing all the key sections. Cards and buttons will guide the user.
- Subtle animations to enhance user experience, such as loading animations and transitions between pages.
